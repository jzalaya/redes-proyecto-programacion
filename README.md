# Redes Neuronales - Proyecto de programación

Proyecto de programación de la asignatura **07MIAR (Redes Neuronales y Deep Learning)**, Máster Universitario en Inteligencia Artificial (VIU).

**Deep Vision in classification tasks**: comparar una CNN entrenada desde cero con una arquitectura preentrenada (transfer learning y fine-tuning) sobre un dataset de imágenes.

## Contenido

- `enunciado/07MIAR_Proyecto_Programacion.ipynb`: enunciado de la práctica con las normas, los criterios de evaluación y los ejemplos de carga desde Kaggle y exportación a PDF.

## Uso

Pensado para ejecutarse en Google Colab. Para descargar el dataset hace falta un token de la API de Kaggle (`kaggle.json`), que no se sube al repo.
